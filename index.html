SECURITY

Designed Around Authorized Access

ATCRS separates student services from restricted administrative and verification functions.

Authorized Access

Different system roles are provided with different levels of access.

Protected Records

Academic information is intended to be accessible only through authorized system functions.

Credential Verification

Released credentials can include verification information such as reference numbers or QR codes.

Separate System Roles

Students access the public Student Portal. Registrar/Admin and Verifier functions are kept in separate private login areas and are not displayed in the public navigation.
