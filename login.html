Terms of Use

ATCRS is intended for authorized academic credential and records processing. Users should provide accurate information and use the system only for legitimate academic purposes.

This development version is a frontend prototype. Do not enter real confidential student records, passwords, payment information, or private academic documents while testing the GitHub version.

ACCOUNT RECOVERY

Forgot Password?

For this development version, password recovery is handled through the account information stored locally in your browser.

A real production version should use secure server-side authentication and email-based password recovery.
