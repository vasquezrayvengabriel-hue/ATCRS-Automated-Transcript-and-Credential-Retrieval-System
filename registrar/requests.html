Registrar Processing Workflow

1. Request

Review the student's submitted document request.

2. Verification

Verify the student's information and academic record.

3. Clearance

Confirm that required clearance requirements are satisfied.

4. Payment

Confirm the applicable payment status before processing.

5. Processing

Prepare and process the requested academic document.

6. Release

Mark the credential as ready for release or completion.

Request Status Guide

Pending

Under Verification

Student information is being verified.

Processing

Document is currently being prepared.

Ready for Release

Completed

Rejected
