Request Processing Workflow

1. Request Submitted — The student, applicant, or alumni submits an academic document request.

2. Registrar Review — The Registrar reviews the request, student information, requested document, purpose, and supporting requirements.

3. Clearance Verification — Required clearance and school records are checked before processing.

4. Payment Verification — Payment status is reviewed before document processing.

5. Processing — The Registrar prepares the requested academic credential.

6. Ready for Release — The completed credential becomes available for the authorized delivery method.

7. Completed — The request is officially completed after release.

Request Status Guide

Statuses used by the Registrar throughout document processing.

Pending

New request waiting for Registrar review.

Under Verification

Student information and requirements are currently being checked.

Clearance Required

The request requires clearance before processing can continue.

Payment Pending

Payment has not yet been verified.

Processing

The Registrar is preparing the requested academic document.

Ready for Release

The credential has been completed and is ready for authorized release.

Completed

The document request has been successfully completed.

Rejected

The request cannot be processed because of an issue with the request or requirements.
